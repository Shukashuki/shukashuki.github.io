# Jerry Lo — Robotics Portfolio

Static English portfolio for GitHub Pages. Copy index.html, style.css, site.js and .nojekyll to your repository root. In Settings → Pages choose Deploy from a branch, main, /(root).

No build, dependencies, analytics, forms or external image assets. All diagrams are editable inline SVG and labeled conceptual, not experimental results.

Edit index.html for content and style.css for layout. site.js provides topic filters and anchor navigation. All studies are visible without JavaScript.

Public-source measurements retain their conditions and limitations. This edition excludes unpublished world-model data, unpublished implementation detail, local tool inventories, tentative dates, personal contact details and third-party imagery. Grasping and safety limitations remain explicit.
